# 로고·글꼴 출처

랜딩은 제공된 브랜드 파일과 위키미디어 공용 SVG를 그대로 씁니다. 모양을 다시 그리지 않았습니다. 단색 마크(OpenAI, Cursor 심볼, X, Claude Code, Codex, Windsurf, Discord)만 다크 모드에서 보이도록 `currentColor` 마스크로 칠합니다.

## 챗통

| 파일 | 용도 |
|---|---|
| `web/public/brand/app-light.png`, `app-dark.png` | 유리 구름 앱 아이콘 A / C1 뭉게 |
| `web/public/favicon.svg`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` | 파비콘, 애플 터치 아이콘 |
| `web/src/assets/hub-cloud.svg` | 히어로 구름 |
| `web/public/brand/lockup-light.png`, `lockup-dark.png` | 로고 락업 |
